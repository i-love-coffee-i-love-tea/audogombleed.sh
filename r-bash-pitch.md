Hey r/bash,

Writing tab-completion scripts by hand is usually a tedious process. Because it takes too much effort, most people skip it entirely, which makes custom CLI tools annoying to use.

To solve this, I put together a lightweight Bash/ZSH framework called **audogombleed**. It focuses on keeping things simple so you can add functional autocomplete to your scripts without dealing with a ton of boilerplate.

**What it offers:**

- **Simple setup:** No massive configuration files or complex completion syntax required.
- **Dual shell support:** Works for both Bash and ZSH.
- **Lightweight:** Zero heavy dependencies, keeping your shell responsive

The project has very little visibility right now, and I would love to get some real-world feedback on it. If you build custom tools for your workflow and want an easy way to add autocomplete, please check it out.

Let me know what you think, what features you'd like to see, or how it works with your setup!
